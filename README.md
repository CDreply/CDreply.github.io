### 🐍 贪吃蛇（v1.2）
- **游戏类型**：休闲、闯关
- **特色功能**：
  - 全新双人模式，支持本地多人对战
  - 多种道具：金苹果、冰冻、双倍积分等
  - 关卡升级系统 + 粒子特效 + 个性化音效
- **操作方式**：
  - 键盘：方向键或 WASD
  - 触摸：滑动操作（移动端）

### 🧩 沉淀方块（v1.1）
- **游戏类型**：益智、策略
- **特色功能**：
  - 炸弹道具系统（概率随等级提升）
  - 实时时间计时 + 空格键使用统计
  - PC 端两栏布局，响应式适配手机／平板
- **操作方式**：
  - 键盘：方向键移动／旋转，空格快速下落
  - 快捷键：P 暂停，B 炸弹
  - 触摸：滑动操作（移动端）

### 🏓 沉哒乒乓（v2.1）
- **游戏类型**：竞技、休闲
- **特色功能**：
  - 新增双人 PvP 模式，可挑战 AI 或与朋友本地对战
  - 连击系统 + 连胜记录
  - 击球力度与角度物理模拟
- **操作方式**：
  - 鼠标／触摸：拖拽控制球拍

### ⚡ 赛博五子棋（v1.2）
- **游戏类型**：棋类、策略
- **特色功能**：
  - 人机对战／双人对战自由切换
  - 赛博朋克霓虹灯效 + 电子音效
- **操作方式**：
  - 鼠标／触摸：点击交叉点落子

### 🎴 简约围棋（v1.2）
- **游戏类型**：棋类、策略
- **特色功能**：
  - 人机模式（AI 执白）／双人模式可选
  - 温润落子音效、支持虚着与悔棋
- **操作方式**：
  - 鼠标／触摸：点击交叉点落子

### ✈️ 几何空战（v2.2）
- **游戏类型**：射击、街机
- **特色功能**：
  - 科幻风格空战射击，多种模式可选
  - 炫酷粒子特效 + 触屏操控
  - 波次关卡制，Boss 战带专属弹幕机制
- **操作方式**：
  - 键盘／触摸：移动与射击，长按蓄力

### 🔫 战术突击（v1.8）
- **游戏类型**：射击、FPS
- **特色功能**：
  - 5 种武器切换、木板掩体与破坏系统
  - HUD 血量弹药 + 小地图雷达
  - 每 5 波刷新 Boss，内置测试模式（口令 `wwssaadd`）
- **操作方式**：
  - 键鼠：WASD 移动 + 鼠标瞄准射击（💻 桌面端）

### 🎯 3D 战术突击（v1.7）
- **游戏类型**：射击、3D 第一人称
- **特色功能**：
  - 4 种武器、穿透系统，霰弹可破坏木质掩体
  - 冲刺、跳跃（空格）、手雷、狙击开镜（右键／Q）
  - 积分商店（B 键，按开不暂停）、每 5 波 Boss
- **操作方式**：
  - 键鼠：WASD 移动 + 鼠标瞄准射击（💻 桌面端）

### 🎱 台球大师（v4）
- **游戏类型**：体育、物理模拟
- **特色功能**：
  - 8 球玩法，人机三档难度 + 本地双人
  - Canvas2D 物理引擎，瞄准辅助线 + 碰撞预测
  - 设置／暂停／撤销，左右侧栏击球记录与战况
- **操作方式**：
  - 鼠标／触摸：拖拽蓄力击球

### 🍪 地图生成模拟器（v1.7）
- **游戏类型**：创意工具、世界观生成
- **特色功能**：
  - 饼干生成法：蓄力捶击 → 自然裂纹 → 板块漂移 → 地形自动解读
  - 三种生成方式：✊ 捶击法／📦 摇晃法／🌠 陨落法（含 ☄ 大陨石模式）
  - 中式美学自动命名、兴趣点、群岛归并，另有 🍽 吃板块与 🔥 暴力模式
  - 一键导出可复制给 AI 续写的世界观 Markdown 文本
  - 种子复现、PNG 导出、移动端长按蓄力
- **操作方式**：
  - 鼠标／触摸：按住蓄力，松手落锤；可多次补击与框选删块

## 🚀 快速开始

### 本地运行
```bash
# 进入项目目录
cd github-pages

# 启动本地服务器
python -m http.server 5500

# 打开浏览器访问
# http://localhost:5500/
```

### 部署到GitHub Pages
1. 将所有文件上传到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择main分支的根目录
4. 访问 https://cdreply.github.io

详细部署步骤请查看 [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)

## 🛠️ 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| HTML5 Canvas | 游戏渲染 | 所有游戏的 2D 画布渲染 |
| Three.js (CDN) | 3D 渲染 | 仅《3D 战术突击》使用 |
| JavaScript | 游戏逻辑 | 完整的游戏实现 |
| Web Audio API | 音效系统 | 不依赖外部音频文件 |
| CSS3 | 样式和动画 | 响应式设计 |
| localStorage | 数据存储 | 保存游戏进度和高分 |
| Jekyll | 静态站点 | GitHub Pages 支持 |

## 🎯 设计理念

### 用户体验
- **简洁直观**：界面清晰，操作简单
- **响应迅速**：实时反馈，无延迟感
- **跨平台**：PC、平板、手机全适配
- **无障碍**：键盘和触摸双重支持

### 技术特色
- **无依赖**：单文件HTML，无需外部库
- **高性能**：优化渲染，流畅运行
- **离线可用**：无需网络连接即可游戏
- **现代标准**：使用最新Web技术

### 游戏设计
- **中文优先**：界面全部使用中文
- **音效定制**：每种游戏有独特音效
- **进度保存**：自动保存游戏记录
- **难度平衡**：精心调整的游戏平衡
