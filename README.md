- **特色功能**：
  - 饼干生成法：蓄力捶击 → 自然裂纹 → 板块漂移 → 地形自动解读
  - 三种生成方式：✊ 捶击法／📦 摇晃法／🌠 陨落法（含 ☄ 大陨石模式）

  - 鼠标／触摸：按住蓄力，松手落锤；可多次补击与框选删块

### 🧊 地图生成模拟器 3D（v1.4.0）
- **游戏类型**：创意工具、世界观生成（2D 版的立体化重构）
- **特色功能**：
  - 沿用 2D 版同一套饼干生成法，但每块碎块都长成有厚度的立体板块
  - **高度即信息**：面积越大、离落锤点越近的板块越高 —— 高差错落本身就是地图信息
  - **断口分色**：外皮色（饼干外焦）／内芯色（断面奶白）分开着色，崖壁带纵向明暗梯度与横向岩层纹
  - **16 种地形**（v1.3）：山脉、山脊、鞍部、陡崖、火山、高原、丘陵、盆地、平原、山谷、峡谷、海峡、海湾、海岸、沙滩、珊瑚礁 —— 每块陆地按「相对海拔 + 起伏度」判出自己的性格，山脉不再泛滥
  - **开场动效**：成图时地貌从海床长出来、天光渐亮、地名逐个淡入（1.1 秒）
  - 五层堆叠（海床 → 海面 → 板块体 → 地貌物 → 标注层），可从任意角度旋转观察
  - **水面 v1.4.0 整体重做**：由「极坐标同心环网格」换成 **96×96 直角网格**（9409 顶点），
    配色改为 smoothstep 连续暗角（近亮青蓝 → 远深蓝黑）—— 从原理上消灭了低角度可见的同心色带；
    同时删掉与水面接缝不齐的侧壁圆柱、把偏棕的底板改深蓝灰并收进水面以内，水面基调由高反射改为哑光
  - **画质自动适配**：帧率不够自动降档（关阴影／降像素比），有余量自动升档，也可手动锁定 高／中／低
  - **成图后自动合批**：进入观赏态把几十个碎块合并成 1 个网格（draw call 110 → 8）；
    阴影改为「按需重画」，加上静止时几乎不渲染 —— 摆着看地图时 GPU 基本不干活
  - Three.js r186 **打包内联进单文件**（约 921KB）：不依赖 CDN、不依赖任何外部文件，双击本地文件即可离线游玩
  - **饼干形状自选**：新饼干旁边的 ▾ 下拉可指定 圆/方/三角/六边/菱形/八边/星星，也可保持随机
  - 同样支持一键导出世界观 Markdown 文本
- **操作方式**：
  - 鼠标：按住饼干蓄力，松手落锤；**在空白处拖拽**旋转视角，滚轮缩放
  - 建议在桌面端使用（移动端可跑但吃性能）

## 🚀 快速开始

### 本地运行
```bash
# 进入项目目录
cd github-pages

# 启动本地服务器
python -m http.server 5500

# 打开浏览器访问
# http://localhost:5500/
```

### 部署到GitHub Pages
1. 将所有文件上传到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择main分支的根目录
4. 访问 https://cdreply.github.io

详细部署步骤请查看 [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)

## 🛠️ 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| HTML5 Canvas | 游戏渲染 | 绝大多数游戏的 2D 画布渲染 |
| Three.js | 3D 渲染 | 《3D 战术突击》走 CDN（r128）；《地图生成模拟器 3D》把 r186 打包内联进单文件 |
| JavaScript | 游戏逻辑 | 完整的游戏实现 |
| Web Audio API | 音效系统 | 不依赖外部音频文件 |
| CSS3 | 样式和动画 | 响应式设计 |
| localStorage | 数据存储 | 保存游戏进度和高分 |
| Jekyll | 静态站点 | GitHub Pages 支持 |

## 📝 更新日志

### 2026-10-28 · 半拍 · 影子对决 v1.3：把「一个玩家一个影子」重构成实体数组
- 新上架第四款对战游戏：**没有 AI、没有随机数**，对手是 0.6 秒前的你自己
- 技术核心：**环形缓冲（1024 槽，2 的幂 + 位掩码）**按时间戳录位置/速度/出拳，
  按 `gameT - delay` 回放并做**帧间插值**（按帧数算延迟在高刷屏上会漂，必须用时间戳）
- 3D 观感不引 three.js：物理仍是圆形平面，绘制时 `ctx.scale(1, 0.56)` 压成椭圆，
  **整只碗在压扁坐标系里画圆**，所有径向渐变自动跟着压扁（省掉手算椭圆渐变）
- v1.3 架构改动：`player/shadow` → `humans[] / ghosts[] / teams[]`，每实体独立缓冲，
  血量上提到队伍（残影模式三影共用一条血），判定统一成「有出拳的实体检查自己的 targets」
- 四种模式：单人 / 双人同屏（各延迟 1 秒，**只能打对方 1 秒前的位置**）/ 残影 ×3（0.6·1.0·1.5 倍）/
  延迟漂移（每 10 秒换档，2.6 秒 smoothstep 过渡，固定序列无随机）
- 调参结论：`GHOST_WIDE` 从 1.45 加到 1.85 机器人结果**完全不变** ——
  影子永远打在你冲出去的落点，撤离 0.6 秒可走 128px，判定放到 105px 仍在圈外。
  **这个游戏「瞄准必中、撤离必不中」，改数值没用，只能改规则**
- 🔴 修复「模式按钮点不动」：文档级 `mousedown`（点哪都开局）抢在 `click` 前 `hideOverlay()`，
  overlay 变 `visibility:hidden` 后 click 永不送达 → 控件统一排除在 mousedown 之外，改走 overlay 事件委托
- 🔴 连带修复：一局结束后 `card.innerHTML` 被结算内容覆盖，**玩家再也回不到模式选择**
  → 启动时留底 `MENU_HTML`，结算页加「换个模式」按钮即可原样恢复
- 验光方式：**肉眼不可靠**。截图上两个相邻影子会糊成一个，改用 `getImageData()` 按色相做
  连通段统计（`P=3[318~344 369~395 433~456]`）才确认三个影子确实分开画出来了
